# FARMER — 3D 힐링 농사 RPG 개발 설계서


## 0. 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 제목 | **FARMER** |
| 부제 | 도시에 지친 귀농인이 마을 이장이 되기까지 |
| 장르 | 3D 힐링 농사 RPG (전투 없음, 시간 압박 없음) |
| 플랫폼 | PC 웹 브라우저 (Chrome / Edge 최신 버전) |
| 기술 | HTML + CSS + JavaScript (ES Modules), 3D 렌더링은 **Three.js** (JS 라이브러리, CDN) |
| 시점 | 밭 전체가 보이는 3인칭 쿼터뷰 (캐릭터 추적 카메라) |
| 클리어 조건 | 이장의 메인 퀘스트 **15개**를 모두 완료 → 마을 이장 취임 엔딩 |
| 저장 | `localStorage` 자동 저장 (잠자기 시 + 주기적) |

### 핵심 게임 루프

```
씨앗 구매 → 밭 갈기 → 씨앗 심기(체력 소모) → 물 주기 → 성장 대기(하루/잠자기 = 체력 회복)
    → 수확(창고로 자동 보관) → 상점 판매 → 돈 획득
    → 장비 강화 · 옷 구매(최대 체력 증가) · 더 좋은 씨앗 구매 · 밭 확장
    → 주민 대화 · 서브 퀘스트 · 이장 메인 퀘스트 → 직책 상승 → (반복) → 마을 이장
```

## 1. 기술 스택 & 실행 방법

### 1.1 사용 기술
- **HTML5**: 게임 캔버스 + UI 레이어(DOM) 구성
- **CSS3**: HUD, 인벤토리, 대화창, 상점 등 모든 UI (둥글고 따뜻한 스타일)
- **JavaScript (ES2020+, ES Modules)**: 게임 로직 전체
- **Three.js (r160 이상)**: 3D 렌더링. 빌드 도구 없이 `importmap` + CDN으로 불러옴
- **Web Audio API**: BGM / 환경음 / 효과음 재생 (에셋이 없으면 코드로 간단한 음 생성)
- **localStorage**: 세이브 데이터

> 번들러(Webpack, Vite 등)·프레임워크(React 등)는 사용하지 않습니다.
> 3D 모델 파일 없이 **Three.js 기본 도형(Box, Cylinder, Sphere, Cone 등)을 조합한 로우폴리 모델**로 제작하여 순수 코드만으로 완성 가능하게 합니다. (추후 `.glb` 모델로 교체 가능하도록 모델 생성 함수를 분리)

### 1.2 Three.js 불러오기 (index.html)

```html
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.160.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.160.0/examples/jsm/"
  }
}
</script>
<script type="module" src="./js/main.js"></script>
```

### 1.3 실행
ES Modules는 `file://`로 열면 동작하지 않으므로 로컬 서버로 실행합니다.
- VS Code / Cursor 확장 **Live Server** 사용, 또는
- `npx serve .` / `python -m http.server 5500` 후 `http://localhost:5500` 접속

## 3. 조작법 (기획서 기준 + 3D 보완)

| 입력 | 동작 | 비고 |
| --- | --- | --- |
| **W A S D** | 캐릭터 이동 | 카메라 방향 기준 이동, Shift = 달리기(보완) |
| **1 ~ 5** | 중앙 하단 핫바 슬롯 선택 | 선택 슬롯 강조 |
| **좌클릭 (밭)** | 선택한 아이템 사용 | 씨앗 → 심기(**체력 소모**) / 호미 → 갈기 / 물뿌리개 → 물주기 |
| **좌클릭 (음식, 인벤토리)** | 음식 먹기 | 체력 회복 (보완) |
| **좌클릭 (수확 표시)** | 다 자란 작물 수확 | 작물 위 아이콘 또는 작물 자체 클릭 |
| **좌클릭 (NPC·건물)** | 상호작용 | 대화(줄 수 있는 퀘스트는 이야기하면 자동 수락), 상점, 대장간, 창고 |
| **좌클릭 (침대)** | 잠자기 | 밤(18:00 이후)에만 가능, 다음 날 아침 6시 |
| **우측 하단 [가방]** | 인벤토리 열기 | 단축키 `I` 또는 `Tab` (보완) |
| **우측 하단 [퀘스트]** | 퀘스트 목록 열기 | 단축키 `Q` (보완) |
| **마우스 휠** | 카메라 줌 인/아웃 | 3D 보완 |
| **우클릭 드래그** | 카메라 회전 | 3D 보완 |
| **Esc** | 열린 창 닫기 / 일시정지 메뉴 | |

### 상호작용 거리 규칙
- 클릭한 대상(밭, NPC, 건물)이 플레이어로부터 **2.5 유닛 이내**일 때만 동작
- 멀리 있으면 해당 위치로 **자동 이동 후 상호작용** (편의성, 힐링 컨셉)
- 클릭 판정은 Three.js `Raycaster`로 처리, 대상 메쉬에 `userData.type`(`plot`, `npc`, `building`, `bed`)을 넣어 구분

## 4. 세계관 & 맵 구성

### 4.1 세계관
도시 생활에 지친 주인공은 시골의 작은 **'초록마을'**로 귀농한다. 남은 것은 **낡은 집과 밭 하나**뿐.
마을 이장은 새로 온 주인공에게 부탁(퀘스트)을 건네고, 주인공은 농사를 짓고 작물을 사고팔며 주민들과 정을 쌓는다.
부탁을 완료할 때마다 마을에서의 **직책이 올라가고**, 15개의 부탁을 모두 마치면 마침내 **마을 이장**이 된다.

### 4.2 맵 레이아웃 (약 80 x 80 유닛, 하나의 연결된 마을)

```
              [ 북쪽 숲 / 시냇물 ]
   ┌───────────────────────────────────────┐
   │   나무   나무     ~~~시냇물~~~   나무     │
   │                                         │
   │  [대장간]      [마을회관/이장]    [주민집]  │
   │                    ■ 광장 ■              │
   │  [상점]          (축제 장소)      [주민집]  │
   │          ════ 마을 길 ════               │
   │                                         │
   │  [주인공 집] [창고]                       │
   │   ┌──────────────┐                      │
   │   │  밭 (3x3 시작)  │ → 확장 시 최대 8x8   │
   │   └──────────────┘                      │
   │   울타리     나무       꽃밭              │
   └───────────────────────────────────────┘
```

- 맵 가장자리는 울타리·나무·언덕으로 막아 밖으로 나가지 못하게 함
- 건물 내부는 별도 씬 없이 **클릭 시 UI 창**으로 처리 (집 → 침대 클릭 가능하도록 집 옆/내부에 침대 오브젝트 노출 또는 집 클릭 시 "잠자기" 메뉴)

### 4.3 주요 시설

| 시설 | 기능 |
| --- | --- |
| 주인공의 집 | 침대 클릭 → 잠자기(다음 날), 저장 |
| 밭 | 시작 3x3(9칸), 퀘스트/구매로 최대 8x8(64칸)까지 확장, 울타리도 함께 넓어짐. 입구의 **'내 밭 · 확장' 팻말**에서 구매 |
| 작물 보관 창고 | 수확한 작물이 **자동으로 입고**, 보관 목록 확인·꺼내기 |
| 상점 | 씨앗 구매, 작물 판매 |
| 대장간 | 농기구 구매·강화, 옷 구매 |
| 마을회관 | 마을 이장 상주, 메인 퀘스트 수락/완료 |
| 주민 집 | 각 주민 상주, 서브 퀘스트 |
| 광장 | 엔딩 임명식 장소 |

## 5. 시간 · 날씨 시스템

### 5.1 시간
- 게임 하루: **06:00 ~ 02:00**
- 시간 흐름: **현실 1초 = 게임 2분** → 하루 약 10분 플레이
- 시간대 구분 (BGM·조명 변화)
  - 아침 06:00 ~ 11:59
  - 낮 12:00 ~ 17:59
  - 저녁/밤 18:00 ~ 02:00
- **잠자기**: 침대 클릭 → 화면 페이드아웃 → 다음 날 06:00 → 작물 성장 처리 → **체력 완전 회복** → 자동 저장
- **밤(18:00 ~ 02:00)에만 잘 수 있음**. 그 전에 집을 클릭하면 "아직 해가 떠 있어서 잠이 오지 않아요"와 함께 남은 시간을 보여 주고 잠자기 버튼은 비활성화
- 02:00가 되면 자동으로 집에서 잠듦 (페널티 없음, 체력도 완전 회복 — 힐링 컨셉)
- UI 창이 열려 있을 때는 시간 정지 (선택 옵션)

### 5.2 낮/밤 연출
- `DirectionalLight`(태양)의 위치를 시간에 따라 회전
- 하늘색(`scene.background`, `fog`)을 시간대별 색으로 보간
  - 아침: 연한 주황/하늘색 · 낮: 밝은 하늘색 · 저녁: 노을 주황 · 밤: 짙은 남색
- 밤에는 집·가로등에 `PointLight` 점등

### 5.3 날씨
매일 아침 날씨를 무작위로 결정합니다.

| 날씨 | 확률 | 효과 |
| --- | --- | --- |
| 맑음 | 60% | 기본 |
| 흐림 | 15% | 조명 약간 어둡게 |
| 비 | 20% | 비 파티클 + 빗소리, **모든 밭 자동 물주기** |
| 눈 | 5% | 눈 파티클 + 지면 흰색 톤, 작물 정상 성장(힐링 컨셉) |

- 파티클: `THREE.Points` 수천 개를 플레이어 주변에서 떨어뜨리고 바닥에 닿으면 위로 재배치
- 우상단 HUD에 날씨 아이콘 표시

## 6. 농사 시스템

### 6.1 밭 칸(FarmPlot) 상태

```
EMPTY(풀밭) ──호미──▶ TILLED(갈린 땅) ──씨앗──▶ PLANTED(1단계)
   ▲                                              │ 물 + 하루 경과
   │                                              ▼
   └──── 수확 후 EMPTY로 복귀 ◀── READY(수확 가능) ◀── GROWING(2~3단계)
```

- 수확은 **낫(또는 파종기)을 들고 있을 때만** 가능. 수확한 칸은 땅이 굳어 EMPTY가 되므로 다시 호미로 갈아야 심을 수 있음

- 각 칸 데이터: `{ state, cropId, daysGrown, watered, plantedDay }` (위치는 `plotPosition(r, c)`로 계산)
- **물 준 날만 성장** (하루 1회). 물 안 줘도 작물이 죽지 않음 — 힐링 컨셉
- 물 준 땅은 색이 진한 갈색으로 변함
- 수확 가능 시 작물 위에 **떠 있는 수확 아이콘**(위아래로 둥실둥실)

### 6.1.1 밭 확장 · 울타리

- 밭은 북동쪽 모서리(출입구 쪽)를 기준으로 **서쪽·남쪽으로** 넓어지고, 울타리도 밭 크기에 맞춰 다시 세워짐
- 출입구 2곳(북동쪽·동쪽)은 크기와 관계없이 그대로 유지, 밖에서 밭을 클릭하면 출입구를 거쳐 자동 이동
- 구매 장소: 밭 입구의 **'내 밭 · 확장' 팻말** 클릭(또는 E), 대장간 '도구 강화' 탭
- 확장 창에는 8x8 미리보기 격자(지금 밭 / 이번에 늘어나는 칸)와 단계별 가격을 표시

| 크기 | 칸 수 | 가격 | 비고 |
| --- | ---: | ---: | --- |
| 3x3 | 9 | - | 시작 |
| 4x4 | 16 | 800원 | 메인 퀘스트 7 보상으로도 획득 |
| 5x5 | 25 | 2,000원 | |
| 6x6 | 36 | 4,000원 | 메인 퀘스트 12 보상으로도 획득 |
| 7x7 | 49 | 7,000원 | |
| 8x8 | 64 | 12,000원 | 최대 |

- 퀘스트 보상 확장 시 이미 그 크기 이상이면 해당 단계 가격만큼 돈으로 대신 지급

### 6.1.2 작물 상세 정보

- 씨앗을 심은(자라는 중인) 밭을 클릭하면 **작물 정보 창**이 열림 (걸어가지 않아도 바로 열림)
  - 물뿌리개를 들고 있고 범위 안에 물이 필요한 칸이 있으면 물주기 우선, 비료를 들고 있으면 비료 사용 우선
- 표시 항목: 작물 이름·등급(★), 성장 단계, 성장 진행 막대(자란 일수 / 전체 일수),
  **다 자라는 날**(N일차 아침, 남은 일수), 오늘 물 상태, 심은 날, 판매가, 예상 수확량·수익(현재 낫 단계 기준),
  심기 체력(세트 효과 반영), 씨앗 가격

### 6.2 성장 단계 모델 (공통 4단계)
1. 씨앗: 흙 위 작은 점
2. 새싹: 작은 초록 잎 2장
3. 성장: 줄기 + 잎 여러 장
4. 다 자람: 작물 고유 모양/색 (예: 토마토 → 빨간 구, 옥수수 → 노란 원기둥)

### 6.4 수확량
- 기본 수확량 1개, **낫 강화 단계**에 따라 증가 (7.2 참고)
- 수확 시 효과음 + 작물이 튀어 오르는 짧은 애니메이션 + "+2 토마토 → 창고" 토스트

### 6.5 수확물 자동 창고 보관
- 수확한 작물은 인벤토리를 거치지 않고 **곧바로 창고에 들어감** (창고까지 들고 갈 필요 없음)
- 연출: 튀어 오른 작물 모델이 작게 줄어들며 창고 건물 방향으로 날아가 사라짐 → 창고 지붕 위에 `+2` 숫자가 잠깐 표시
- 창고는 작물 종류별로 개수만 쌓이는 구조라 **가득 차는 일이 없음** → 수확이 막히지 않음
- 처리 순서

```js
// systems/FarmSystem.js
harvest(plot) {
  const amount = ToolSystem.getHarvestAmount();          // 낫 단계에 따른 수확량
  StorageSystem.add(`crop_${plot.cropId}`, amount);     // 창고로 바로 입고
  EventBus.emit('harvest', { cropId: plot.cropId, amount }); // 퀘스트·통계 갱신
  plot.reset();                                          // TILLED 상태로 복귀
}
```

## 7. 체력 · 장비 · 옷 시스템

### 7.1 체력 (Stamina)

#### 기본 규칙
- 기본 최대 체력: **100**
- **씨앗을 심을 때만 체력이 닳음** (갈기·물주기·수확·이동은 체력 소모 없음)
- 소모량은 작물마다 다르며, **판매가가 높은 좋은 작물일수록 더 많이 닳음** (6.3 작물 표의 `심기 체력`)
- 현재 체력이 심으려는 작물의 소모량보다 적으면 심을 수 없음
  - 토스트: "너무 피곤해요… 잠을 자거나 음식을 먹고 쉬어 가요 😴"
  - 이동·물주기·수확·대화·판매 등 다른 행동은 그대로 가능 (전투/실패 없는 힐링 컨셉 유지)
- 체력이 0이 되어도 기절·페널티 없음

#### 소모량 계산

```js
// systems/StaminaSystem.js
function getPlantCost(cropId) {
  const base = CROPS[cropId].staminaCost;
  const reduce = OutfitSystem.getPlantCostReduce();   // 세트 효과 (0 ~ 0.3)
  return Math.max(1, Math.round(base * (1 - reduce)));
}
```

- 호미/물뿌리개 강화로 여러 칸을 한 번에 처리하더라도, 씨앗은 **1칸 심을 때마다** 소모량이 적용됨

#### 회복
| 방법 | 회복량 | 비고 |
| --- | --- | --- |
| 잠자기 (침대 / 02:00 자동 취침) | **최대 체력까지 완전 회복** | 기본 회복 수단 |
| 음식 먹기 | 음식별 고정량 (아래 표) | 인벤토리·핫바에서 선택 후 사용 |
| 자연 회복 | 게임 시간 1시간당 +2 | 마지막으로 심은 뒤 게임 시간 30분이 지나야 시작 |

#### 음식 아이템 (`type: 'food'`)
| ID | 이름 | 회복량 | 획득 |
| --- | --- | ---: | --- |
| `food_bread` | 새참 빵 | 20 | 상점 구매 40원 |
| `food_tea` | 시냇물 약초차 | 30 | 오 씨 서브 퀘스트 1 보상 x3, 오 씨 서브 퀘스트 2 완료 후 상점 구매 80원 |
| `food_lunchbox` | 할머니 도시락 | 50 | 김 할머니 서브 퀘스트 1 보상 x3 |

#### 체력 UI
- 좌측 상단 플레이어 정보 아래 **체력 바** (`현재 / 최대`, 예: `82 / 140`)
  - 50% 이상 초록 · 20~50% 노랑 · 20% 미만 주황
- 씨앗을 들고 밭에 마우스를 올리면 체력 바에 **소모 예정량을 반투명하게 미리 표시**
- 심을 때 체력 바 옆에 `-6` 같은 숫자가 떠올랐다 사라짐
- 체력이 부족한 상태에서 씨앗을 들면 밭 위 커서가 빨간색으로 표시

### 7.2 농기구 (대장간에서 구매/강화)

| 도구 | 용도 | 강화 효과 |
| --- | --- | --- |
| 호미 | 땅 갈기 | 작업 속도↑, 단계가 오르면 한 번에 여러 칸 갈기 |
| 물뿌리개 | 물 주기 | 작업 속도↑, 한 번에 여러 칸 물주기 |
| 낫 | 수확 | 수확량↑ |

| 단계 | 이름 | 강화 비용 | 호미/물뿌리개 범위 | 낫 수확량 | 작업 시간 |
| --- | --- | ---: | --- | --- | --- |
| 1 | 낡은 | 기본 지급 | 1칸 | 1개 | 0.8초 |
| 2 | 구리 | 300 | 1칸 | 1~2개 | 0.6초 |

| 4 | 금 | 2,000 | 3x3칸 | 2~3개 | 0.3초 |
| 5 | 무지개 | 5,000 | 3x3칸 | 3개 | 0.15초 |

- "작업 시간" 동안 캐릭터가 도구를 휘두르는 짧은 애니메이션 후 효과 적용
- 수확은 낫이 없어도 가능(손으로 1개), 낫을 핫바에서 들고 있으면 낫 효과 적용 — *구현 단순화를 위해 "소지만 하면 적용"으로 해도 됨*

### 7.3 옷 (최대 체력 증가 + 세트 효과)

#### 기본 규칙
- 옷 종류는 **모자 / 상의 / 하의** 3부위
- 부위마다 1개씩 착용, 착용한 옷은 **최대 체력을 늘려 줌**
- 시작 시 옷 없음(최대 체력 100). 옷은 인벤토리 20칸을 차지하지 않고 **옷장 목록**에 따로 보관되며 인벤토리의 `옷` 탭에서 확인
- 같은 세트의 **모자 + 상의 + 하의 3개를 모두 착용하면 세트 효과** 발동
  - 2개만 같은 세트일 때는 세트 효과 없음 (UI에 `2/3`로 진행도 표시)
- 옷을 입으면 플레이어 3D 모델의 해당 부위 메쉬(모양·색)가 바뀜
- 옷을 벗거나 바꿔서 최대 체력이 줄면, 현재 체력은 새 최대 체력을 넘지 않도록 깎임 (`current = Math.min(current, max)`)

#### 최대 체력 계산

```js
// systems/OutfitSystem.js
maxStamina = 100
  + (hat?.stamina ?? 0) + (top?.stamina ?? 0) + (bottom?.stamina ?? 0)
  + (isFullSet() ? SETS[hat.setId].bonus.stamina : 0);

function isFullSet() {
  return hat && top && bottom && hat.setId === top.setId && top.setId === bottom.setId;
}
```

## 8. 인벤토리 · 핫바 · 창고

### 8.1 핫바 (중앙 하단, 5칸)
- 1~5 키로 선택, 선택 슬롯 테두리 강조 + 플레이어 손에 해당 도구/씨앗 표시
- 시작 핫바: `[호미] [물뿌리개] [낫] [상추 씨앗 x10] [빈칸]`

### 8.2 인벤토리 (우측 하단 가방 버튼)
- 탭: `씨앗 / 작물 / 음식 / 물품 / 채광 / 낚시 / 시설 / 장비`
- 장비 외 탭은 **탭마다 따로 된 칸**(20칸, 낚시는 40칸) — 아이템은 종류에 맞는 탭 칸에만 들어감. 핫바 7칸은 아무 종류나 가능
  - 물품: 타우린 · 키토산 · 일반 흙 · 토양 흙 · 비료 같은 재료·특별 아이템
  - 채광: 곡괭이 · 광석 / 낚시: 낚싯대 · 물고기 · 게(한 칸에 한 마리, 무게 표시) / 시설: 약탕기 · 육묘장(눌러서 '배치하기')
  - 아이템을 고르면 '⬇ 핫바로 옮기기' / '🎒 가방에 넣기' 버튼으로 바로 옮길 수 있음
- 장비 탭은 농기구 장비 목록, 옷 탭은 옷장 목록
- 창 왼쪽에 옷 착용 슬롯(모자/상의/하의)과 체력 정보 표시 (7.3 옷 UI 참고)
- 같은 아이템은 **최대 99개 스택**
- 좌클릭으로 선택 → 강조 표시 → 핫바 슬롯 클릭 시 해당 슬롯에 등록
- 기획서 동작: "인벤토리에서 씨앗 좌클릭 → 밭 좌클릭 → 심기"도 지원 (인벤토리에서 선택한 아이템이 '현재 들고 있는 아이템'이 됨)

### 8.3 창고
- **수확한 작물은 모두 창고로 자동 입고** (6.5 참고)
- 창고에는 작물만 보관, 작물 종류별 개수로 저장하며 **용량 제한 없음**
- 창고 클릭 → 좌측 인벤토리 / 우측 창고 창
  - 창고 목록: 작물 아이콘 · 이름 · 보유 개수 · 개당 판매가 · 총 가치
  - 작물을 클릭하면 인벤토리로 꺼내기(1 / 10 / 전부), 인벤토리의 작물을 클릭하면 다시 창고로 넣기
- 상점 판매와 퀘스트 전달 시 **창고의 작물을 바로 사용** — 창고에 가서 꺼내 올 필요 없음
  - 사용 순서: 인벤토리에 들고 있는 작물 먼저 → 부족한 만큼 창고에서 차감
- 퀘스트 진행률(`deliver` 조건)은 인벤토리 + 창고 수량을 합쳐서 표시 (예: `토마토 3/5`)

## 10. 퀘스트 시스템

### 10.1 공통 구조

```js
{
  id: 'main_01',
  type: 'main',            // main | sub
  giver: 'chief',
  title: '마을에 온 것을 환영하네',
  desc: '마을 사람들에게 인사를 해 보자.',
  objectives: [            // 조건 종류: talk, plant, harvest, sell, earn, deliver, upgrade, buy, expand, relation, sleep
    { kind: 'talk', target: ['shop', 'smith', 'grandma'], count: 3 }
  ],
  location: { x: 10, z: -5 },  // 퀘스트 위치 표시용

}
```

### 10.6 낚시 (`data/fishing.js`, `systems/FishingSystem.js`)

- 오 씨 퀘스트로 대나무 낚싯대 → 핫바에서 골라 시냇물 클릭 → 찌 던지기 → 찌에 ❗가 뜨면 클릭/Space로 챔질 (놓치면 다시 기다림, 일찍 당기면 대기 +1.5초, 이동하면 그만둠)
- 물고기 20종(★1~★5 × 4종) + 게 3종(★2 참게, ★3 꽃게, ★5 황금 대게). 무게는 종마다 범위가 있고 가벼운 쪽이 흔함
- 잡은 고기는 가방 '낚시' 칸(40칸, 한 칸에 한 마리 · 무게 보관) → 오 씨에게 교환: 물고기 → 타우린, 게 → 키토산 (타우린·키토산은 '물품' 칸)
  - 교환량 = 등급 기본량(1·2·4·7·12) × (무게 / 평균 무게), 최소 1
- 낚싯대 4종: 대나무(퀘스트) · 카본 1,200 · 프로 3,000 · 황금 7,000원 — 입질이 빨라지고, 챔질 여유가 길어지고, 높은 등급 확률↑
- 오 씨 가게 탭: 어망 교환 / 낚싯대 / 물고기 도감(종류별 최고 무게)

### 10.7 시설: 약탕기 · 육묘장 (`data/facilities.js`, `systems/FacilitySystem.js`)

- 상점 '🏡 시설·흙' 탭에서 구매 → 원하는 빈 땅에 직접 배치 (R 회전, Esc 취소). 길·밭(최대 8x8 자리)·광장·시냇물·건물/주민 자리 위는 불가
- 약탕기 2.5×2.5m (창고의 1/4), 2,500원 / 육묘장 5×2.5m (약탕기 2배, 비닐하우스), 5,000원 — 종류별 최대 3개
- 약탕기: 일반 흙 1(상점 20원) + 타우린 3 + 키토산 1 → 토양 흙 1 (개당 게임 20분)
- 육묘장: 씨앗 1 + 토양 흙 1 → 모종 1 (개당 게임 30분)
- 모종은 씨앗처럼 심고, 성장 일수가 1/3 (반올림, 최소 1일 — 수박 10일 → 3일)
- 배치한 시설을 누르면 제작 · 꺼내기 · 위치 옮기기 · 거둬들이기

### 10.8 광산 (`data/mining.js`, `systems/MiningSystem.js`, `world/Mine.js`)

- 마을 동쪽 끝 광산 입구. 윤 씨 아주머니 퀘스트를 깨면 "남편이 일하는 광산"에 들어갈 수 있음
- 광산 안(별도 공간): 한 반장(윤 씨 남편) — 첫 대화에 낡은 곡괭이 지급, 광석 매입 / 돌쇠 — 곡괭이 판매
- 광맥 18자리: 매일 아침 모두 다시 차고, 캐낸 자리는 게임 시간 약 3시간 뒤 다시 생김
- 광석: 석탄 5 · 구리 10 · 철 18 · 은 30 · 금 50 · 자수정 100원 (등급 높은 광석은 좋은 곡괭이 필요)
- 곡괭이 5종: 낡은(지급) · 구리 600 · 철 1,500 · 금 3,500 · 다이아 8,000원 — 캐는 시간↓, 광석 추가 확률 5→15→25→40→55%
- 한 번 캘 때 체력 2~3 소모 (농사와 같은 체력) → 벌이가 농사를 넘지 않는 쉬어 가는 콘텐츠
- 광석 판매액은 '누적 판매 금액'(메인 퀘스트) 에 포함되지 않음

## 13. 그래픽 컨셉 (3D)

> 추가 요청으로 실사풍 → 다시 **동물의 숲 느낌(실사 조명 + 아기자기·동글동글한 형태)**으로 조정 (아래가 현재 기준)

- **형태**: 키 약 1.8m에 통통하고 둥근 체형, 큰 눈·볼터치·미소가 있는 동그란 얼굴의 캐릭터 / 모서리가 둥근 건물(알록달록한 지붕·하늘색 유리창) / 뭉게구름 같은 동그란 잎 덩어리 나무·덤불 / 둥근 가로등·울타리 / 실제 비율의 트랙터·파종기(밝은 색)
- **색감**: 밝은 잔디, 모래빛 흙길, 파스텔 벽과 선명한 지붕, 청록색 시냇물, 밝은 옷 색
- **재질**: 장난감처럼 무광인 `MeshStandardMaterial` + `js/world/Textures.js`에서 캔버스로 그리는 대비 낮은 텍스처(풀 무늬 잔디·모래빛 흙길·둥근 판석·비늘 기와·조약돌 벽·잎 무늬 등). 요철(노멀맵)은 기와·돌·밭 고랑 정도에만 은은하게 — 외부 이미지 파일 없음
- **조명**: 파스텔 그라데이션 하늘 돔(시간대별 색) + 하늘을 구운 환경맵 + `DirectionalLight`(해/달, 부드러운 그림자) + 넉넉한 `HemisphereLight`, 색이 탁해지지 않게 `Linear` 톤 매핑
- **하늘·물**: 천천히 떠다니는 뭉게구름, 청록색 시냇물과 하얀 물거품 띠
- **연출 추가**: 물뿌리개를 기울이면 꼭지에서 물방울이 톡톡 떨어지고 땅에 닿으면 작게 튐 (`Effects.waterDrop`)
- **그림자**: `PCFSoftShadowMap` 4096
- **카메라**: `PerspectiveCamera`(FOV 42), 플레이어 뒤 위쪽에서 부드럽게 추적(lerp), 줌 범위 8~25
- **안개(FogExp2)**: 시간·날씨에 따라 색과 농도가 바뀜
- **최적화**: 들풀·꽃밭은 `InstancedMesh`, 꽃 한 송이·나무 잎은 지오메트리 하나로 합침
- **연출**: 작물이 바람에 살짝 흔들림, 나무 흔들림, 시냇물 반짝임(텍스처 오프셋), 수확 시 튀어오름, 걷기 시 캐릭터 상하 흔들림

## 15. 엔딩

예고편처럼 연출되는 밤의 광장 (`ui/EndingUI.js`)

1. 마지막 메인 퀘스트(16) 완료 보고 → '마을 이장' 직책 → 화면 페이드, 위아래 검은 띠(영화 화면)
2. 어두운 밤(연출 중에만 하늘·조명을 밤으로, 실제 게임 시간은 그대로) — 민지가 뛰노는 광장 큰 나무에 **꼬마전구**(나선 + 기둥으로 이어진 전구 줄)
3. 자막 "그날 밤, 초록마을 광장" → 마을 주민 모두(광산의 한 반장·돌쇠 포함)가 나무 앞에 모임, 카메라가 천천히 회전
4. 박 이장 ↔ 귀농인 근접 컷 — "내 자네를 이 마을의 이장으로 인정하네!" → 귀농인 인사
5. **모두 박수** (박수 동작 + 박수 소리 + 꽃가루), 민지는 두 팔 들고 환호
6. 주민마다 얼굴 컷 + 축하 한마디, 귀농인 답사
7. 카메라가 물러나며 "🎉 게임을 클리어해 주셔서 감사합니다!" → 감사 카드(플레이 통계)
8. [계속 플레이하기] — **게임은 초기화하지 않음**. 이장 직책·돈·가방 그대로 남은 콘텐츠 계속. 꼬마전구는 그 뒤로 밤마다 켜짐
9. 메뉴(Esc)의 '🎬 엔딩 다시 보기'로 언제든 다시 볼 수 있음

- [ ] 농기구 강화 시 작업 속도와 수확량이 실제로 증가한다
- [ ] 씨앗을 심으면 체력이 닳고, 판매가가 높은 작물일수록 더 많이 닳는다
- [ ] 체력이 부족하면 심을 수 없고, 잠자기·음식으로 회복된다
- [ ] 모자/상의/하의를 입으면 최대 체력이 늘고, 같은 세트 3부위를 입으면 세트 효과가 발동한다
- [ ] 주민과 대화하며 친밀도가 오르고, 서브 퀘스트로 특별 아이템을 얻는다
- [ ] 이장 퀘스트 15개를 순서대로 깨면 직책이 오르고, 마지막에 이장 임명 엔딩이 나온다
- [ ] 침대 클릭으로 다음 날 아침이 된다
- [ ] 낮/밤, 비/눈이 3D로 표현된다
- [ ] 좌상단(정보·직책·소지금), 우상단(날짜·시간·날씨), 우하단(퀘스트·인벤토리), 중앙 하단(핫바) UI가 배치되어 있다
- [ ] 퀘스트 클릭 시 조건과 위치가 표시된다
- [ ] 시간 제한·전투·실패 페널티 없이 편안하게 플레이할 수 있다
- [ ] 새로고침 후 이어하기가 가능하다
